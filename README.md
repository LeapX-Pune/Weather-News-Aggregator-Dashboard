# Weather Dashboard

A simple weather dashboard project skeleton with separate JavaScript modules for weather, news, and UI logic.

## Project structure

- `index.html` – main HTML file
- `css/styles.css` – project stylesheet
- `js/app.js` – main application entry point
- `js/weather.js` – weather data module
- `js/news.js` – news data module
- `js/ui.js` – UI rendering module
- `assets/icons-images/` – folder for icons and image assets

## Usage

Open `index.html` in your browser. The sample data is currently mocked in `js/weather.js` and `js/news.js`.
